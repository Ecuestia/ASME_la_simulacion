Les sugiero que si quieren reclutar talento, les pregunten a mis colegas un resumen de lo que hicieron.
Creamos este programa con el propósito de ayudar a más estudiantes de ingeniería química (o a cualquiera que disfrute dimensionando equipos de proceso).

El código está escrito para leer archivos de DWSIM guardados como .dwxml y .dwxmz; cualquier otro, les tocará a ustedes implementarlo.

Para que funcione, les recomiendo descargar el código en una carpeta que sea su "entorno de trabajo" y que a los archivos que les vayan a hacer dimensionamiento guarden una copia ahí mismo.
También los aliento a que sigan trabajando en el código, las aportaciones y mejoras que le hagan serán totalmente suyas y pueden emplearlas como más les guste.
No es publicidad, pero desconozco cómo hacerlo funcionar sin Visual Studio Code.
